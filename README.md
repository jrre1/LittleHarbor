# LittleHarbor · 小小港湾

一个简洁的静态欢迎页，使用暖色背景和帆船插画，适配电脑与手机。

## 文件

- `index.html`：完整首页，包含样式和内联 SVG 插画。
- `README.md`：项目说明。

## 使用

下载后，直接用浏览器打开 `index.html` 即可。也可以把这两个文件放到支持静态文件的网站托管服务。

无需安装依赖、构建工具或配置账号。页面没有外部资源请求、统计追踪、登录功能和数据存储。

## 修改

在 `index.html` 中修改标题、介绍文字和卡片内容即可。颜色在顶部的 CSS 变量中设置。

这是独立编写的示例主页，不包含其他业务项目的代码或数据。
